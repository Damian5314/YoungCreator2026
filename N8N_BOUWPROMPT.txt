--- CODE START: "Map results" (plak letterlijk) ---
// Google-resultaten → ruwe items voor de app (title, url, description, kind, query).
// De app vult bedrijf, type, locatie en 'why now' zelf aan met AI (of regels).
// Apify geeft één record per resultatenpagina: { searchQuery: { term }, organicResults: [{ title, url, description }] }
const MAX_ITEMS = 60;
const input = $('Build Apify input').first().json;
const kindByQuery = new Map(input.plan.map((entry) => [String(entry.query).trim().toLowerCase(), entry.kind]));

const lists = [];
for (const page of $input.all()) {
  const term = String(page.json.searchQuery?.term ?? '').trim();
  const kind = kindByQuery.get(term.toLowerCase()) ?? 'job';
  lists.push(
    (page.json.organicResults ?? [])
      .filter((result) => result.url && result.title)
      .map((result) => ({ title: result.title, url: result.url, description: result.description, kind, query: term, source: 'web' })),
  );
}

// Om en om per zoekterm, zodat alle soorten (job, event, hackathon, startup, news) binnen de limiet aan bod komen
const seen = new Set();
const items = [];
for (let rank = 0; items.length < MAX_ITEMS && lists.some((list) => rank < list.length); rank++) {
  for (const list of lists) {
    const item = list[rank];
    if (!item || seen.has(item.url)) continue;
    seen.add(item.url);
    items.push(item);
    if (items.length >= MAX_ITEMS) break;
  }
}

return [{ json: { runId: input.runId, callbackUrl: input.callbackUrl, items } }];

--- CODE START: "Attach contacts" (plak letterlijk) ---
// Beste e-mailadres per website aan de items hangen (jobs@/careers@ > hello@/info@ > de rest; eigen domein eerst)
// Apify (mergeContacts) geeft één rij per start-URL: { originalStartUrl, domain, emails: [] }
const mapped = $('Map results').first().json;
let rows = [];
try {
  rows = $('Apify: Contact details').all().map((item) => item.json);
} catch {
  rows = []; // geen bedrijfssites gevonden: contact-stap is overgeslagen
}

const hostOf = (value) => {
  try {
    return new URL(String(value)).hostname.toLowerCase().replace(/^www\./, '');
  } catch {
    return '';
  }
};
const NOISE = /(\.(png|jpe?g|gif|webp|svg)$|^no-?reply@|@(sentry[\w.-]*|[\w.-]*wixpress\.com|example\.(com|org|net)|domain\.com|email\.com)$)/;
const rank = (email, host) => {
  const role = /^(jobs|careers?|werken|recruit\w*|talent|hr|people)@/.test(email) ? 0 : /^(hello|hi|info|contact)@/.test(email) ? 1 : 2;
  const site = host.split('.').slice(-2).join('.');
  return role + (email.endsWith('@' + site) || email.endsWith('.' + site) ? 0 : 3);
};
const emailByHost = new Map();

for (const row of rows) {
  const host = hostOf(row.originalStartUrl) || String(row.domain || '').toLowerCase().replace(/^www\./, '') || hostOf(row.url);
  const emails = (row.emails || [])
    .map((email) => String(email).trim().toLowerCase())
    .filter((email) => /^[^@\s]+@[^@\s]+\.[a-z]{2,}$/.test(email) && !NOISE.test(email));
  if (!host || emails.length === 0) continue;
  const best = emails.sort((a, b) => rank(a, host) - rank(b, host))[0];
  if (!emailByHost.has(host) || rank(best, host) < rank(emailByHost.get(host), host)) emailByHost.set(host, best);
}

const items = mapped.items.map((item) => {
  const email = emailByHost.get(hostOf(item.url));
  return email ? { ...item, contact: { email } } : item;
});

return [{ json: { runId: mapped.runId, callbackUrl: mapped.callbackUrl, done: true, items } }];
--- CODE EINDE: "Attach contacts" ---

     curl -i -X POST "<N8N_SEARCH_WEBHOOK_URL>" -H "content-type: application/json" -d "{}"
   Verwacht: 403 "Authorization data is wrong!". Krijg je 200? Dan staat Header Auth niet aan.

3. Zoeken: log in op de app → Search → "Search".
   In n8n → Executions zie je "JobHunter — Zoeken" lopen (1–4 min).
   Groen = resultaten staan op het dashboard. Rood bij "Apify: Google Search"
   = check het Apify-token/tegoed; de app zet de run op failed en geeft de credit terug.
   Rood bij "Send results to app" = check APP_URL en de "n8n → JobHunter"-credential
   (401 = verkeerd geheim).

4. Planning met de hand:
     curl -X POST "{APP_URL}/api/n8n/scheduler" -H "Authorization: Bearer <N8N_SECRET>"
   Verwacht: {"ok":true,"started":…,"expiredRuns":…,"results":[…]}

5. Mailen: Settings → automatiseringsniveau 2. Open een match met een concept-mail,
   zet de ontvanger op JE EIGEN adres, klik "Approve & send".
   Verwacht: mail in je inbox met afzendernaam = student, "Reply-To" = student.
   Mislukt? De foutmelding van Gmail staat bij de mail in de app.


================================================================================
DEEL 8 — LIMIETEN EN VALKUILEN
================================================================================

- n8n Cloud Starter: 2.500 executions per maand. Elke zoekopdracht = 1, elke mail
  = 1, elke planningsronde = 1. Daarom planning op 30 minuten.
- n8n Cloud trial: runs worden na 180 s afgebroken. Een zoekrun met Apify kan
  langer duren; test op een betaald plan of self-hosted.
- Webhooks op n8n Cloud moeten binnen 100 s antwoorden. Zoeken antwoordt meteen;
  mailen wacht alleen op Gmail (enkele seconden). Niets aan veranderen.
- Apify: synchrone runs mogen max. 300 s. De workflow gebruikt 240 s (Google) en
  180 s (contactgegevens). Gaat Google over de tijd, dan meldt de workflow dat aan
  de app en krijgt de student de credit terug.
- Gmail: max. 500 mails per dag (gratis account). De app begrenst zelf al:
  niveau 3 standaard 3 per dag, handmatig max. 25 per 24 uur.
- Privacy (AVG): n8n bewaart standaard de invoer van elke run, dus ook de
  profielgegevens van de student en de mailteksten. Zet per workflow in
  Settings → "Save successful production executions" op "Do not save"
  (mislukte runs wel bewaren om te debuggen).
- Self-hosted n8n + een localhost-APP_URL: vanaf n8n 3.0 (oktober 2026) blokkeert
  n8n verzoeken naar localhost/privé-adressen. Gebruik een publieke URL (ngrok/Vercel).
- Google News RSS NIET toevoegen als bron: de voorwaarden staan alleen
  persoonlijk, niet-commercieel gebruik toe (en de Engelse NL-editie bestaat niet).
- Lokaal testen zonder n8n en zonder Apify-kosten: npm run mock:n8n (zie docs/n8n.md).
